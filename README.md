## 📌 Project Overview

An interactive, responsive browser-based quiz application developed during **Lecture 10**. It features a modern interface to practice core Computer Science, Web Development (HTML/CSS/JS), and Git fundamentals.

---

## ✨ Features

- **Interactive Question Flow:** Smooth transition between question cards with dynamic progress bar tracking.
- **Immediate Feedback:** Instant visual indication of correct and wrong choices with contextual explanations.
- **Real-time Scoring:** Live score updates throughout the quiz.
- **Responsive & Accessible Design:** Works on all devices (mobile, tablet, desktop) with high-contrast accessibility.
- **Results & Replay:** Final score calculation, personalized performance messaging, and single-click restart.

---

## 💻 Tech Stack

- **HTML5:** Semantic layout (`<header>`, `<main>`, `<button>`).
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS transitions.
- **JavaScript (ES6):** Dynamic DOM manipulation, array iteration, state management.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. No build tools or dependencies required!
